# alfa_core_app_api

**AlfaCore — Companion App API**

JWT-authenticated REST API for the AlfaCore PWA. Pulls entire platform via transitive deps.

## Role in AlfaCore

This module is part of the AlfaCore Luxury Automotive Service Platform.

For complete architecture and rationale, see the **AlfaCore Architecture** workspace in Odoo Knowledge, specifically the Application Architecture Blueprint document.
